# Schaefer TX — Netlify site scaffold

This repository contains a small Vite + React site intended to be deployed on Netlify.

To deploy:
1. Push this branch to GitHub (already done).
2. In Netlify: New site → Import from Git → connect GitHub and choose subch/schaeferTX
3. Build command: npm run build
   Publish directory: dist

Local development:
- npm install
- npm run dev

Privacy note: Westgard demo parses CSV files in the browser; nothing is uploaded.
