Batch Builder

Hamilton plate workbook → Ascent batch files. Source, for building on the lab network.

This is a sanitised copy. Database credentials, server names, batch numbers and specimen identifiers have been replaced with synthetic values. It runs and all tests pass, but it will not reach a real database until you supply the real connection details locally, as described in step 3.

Getting it running

  1. Get the files. Use the download button above, or grab individual files from the list below. Keep the folder layout: the tests and the build both rely on it.
  2. Set it up. Needs Python 3.10 or newer. 
    python make.py setup
    Creates an isolated environment, installs dependencies and runs the test suite. You should see 236 passed. Nothing is installed machine-wide.
  3. Add your connection details. Create batchbuilder.json next to make.py: 
    {
  "apollo": {
    "server": "YOUR_SERVER\\INSTANCE",
    "database": "YOUR_DATABASE",
    "uid": "YOUR_USER",
    "pwd": "YOUR_PASSWORD"
  }
}
    Anything you put here overrides the placeholders in the source. This file is git-ignored and is not part of the download.
  4. Try it. 
    python make.py run
    Starts a local web page in your browser. It runs on 127.0.0.1 only — nothing is exposed on the network. Add --demo to try the interface with no database at all.
  5. Build the executable, once you are happy it works. 
    python make.py build
    Produces build/dist/BatchBuilder/. Copy that entire folder to wherever analysts run it from — the .exe needs the _internal folder beside it.

python make.py lists every task. python make.py doctor reports what is installed and what is missing without changing anything. Full detail, including troubleshooting, is in BUILD.md.
